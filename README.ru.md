# AOD для Android

Приложение для постоянно включённого экрана и режима StandBy во время зарядки в горизонтальном
положении. Написано на Java и стандартном Android Framework, без Gradle и сторонних библиотек.

## Возможности

- Приглушённый экран блокировки с системными обоями, часами, датой, зарядом, будильником и уведомлениями.
- Краткое повышение яркости при поднятии телефона или касании.
- Режим StandBy при зарядке в горизонтальном положении: часы и карточки состояния.
- Затемнение по датчику приближения, отключение в энергосберегающем режиме и красная тема StandBy в темноте.
- Содержание уведомлений скрыто по умолчанию. Его можно разрешить отдельно в настройках приложения.

## Разрешения и приватность

Для AOD нужны разрешение показа поверх других окон и, для более надёжной работы, отключение
оптимизации батареи. Для карточек уведомлений нужен отдельный доступ Android к уведомлениям.
Приложение читает активные заголовки и тексты уведомлений локально и не отправляет их в сеть.
По умолчанию показывается только название приложения. Карточки можно выключить или отдельно
разрешить показ их текста.

## Сборка APK

Нужны JDK 17, Android SDK Platform 36, Android Build Tools 36, Python 3, а также команды
`aapt2`, `d8`, `apksigner` и `keytool` из Build Tools в `PATH`.

```sh
ANDROID_HOME=/path/to/Android/Sdk \
ANDROID_BUILD_TOOLS=/path/to/Android/Sdk/build-tools/36.0.0 \
bash ./build-apk.sh .
```

Путь к платформе можно задать отдельно через `SDK_JAR`. APK появится в `build/app.apk`. При первой
сборке скрипт создаёт ключ подписи в `~/.android/aod-signing`. Храните ключ и пароль вне репозитория:
для обновлений нужна та же подпись.

Английская версия: [README.md](README.md).

## Совместимость

Проект рассчитан на Android 36 и поддерживает Android 8.0 (API 26) и новее. Поведение AOD,
ограничения фоновой работы, датчики и энергосбережение зависят от производителя телефона;
проверьте работу на нужном устройстве. Если датчика приближения или освещённости нет, связанные
с ним функции не работают.
